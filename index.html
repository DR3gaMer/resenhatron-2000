⚠️ Permissão bloqueada no Firestore (Missing or insufficient permissions)

No Console do Firebase, vá em Firestore Database → Regras (Rules), cole o código abaixo e clique em Publicar:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Todos os amigos devem usar o mesmo Código da Sala para compartilharem os mesmos dados ao vivo.
